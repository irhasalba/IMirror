iMirror - mirror your iPhone screen to Windows (AirPlay receiver, based on UxPlay 1.74)

1. Run iMirror.exe and click Start.
2. Put the iPhone and PC on the same Wi-Fi. On the iPhone: Control Center > Screen Mirroring > iMirror.
3. Alt+Enter = fullscreen. Click Stop to end.

Requires: Bonjour Service (install "Bonjour Print Services for Windows" from Apple).
If the iPhone doesn't see "iMirror": make sure the Windows network is set to Private, not Public,
and allow iMirror/uxplay in Windows Firewall on Private networks.
